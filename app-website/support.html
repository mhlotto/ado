Ado Support

Ado is currently under development. This page is being prepared for future public distribution.

Back up your data

Ado stores its working data locally. Before uninstalling the app, changing to a differently signed build, or moving to another device, use Ado's data backup feature to export a JSON backup to a location outside the app.

Calendar import

Calendar import requires Android calendar read permission. If calendar items cannot be imported, check Ado's permissions in Android system settings and confirm that calendar access is enabled.

Restore from a backup

Use Ado's import feature and select a previously exported JSON backup. If matching local records already exist, Ado may ask whether to overwrite them or keep the local versions.

Contact

A public support contact has not yet been published. Contact information will be added before Ado is submitted to a public app store.

For information about how Ado handles data, see the Ado Privacy Policy.
