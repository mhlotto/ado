Ado Privacy Policy

Effective: August 23, 2026

This Privacy Policy describes how the current Android version of Ado handles information. Ado is designed as a local-first task and checklist application.

Summary: Ado does not require an account and does not use advertising or analytics SDKs. Its working data is stored on your device. Ado can read calendar events only if you grant calendar permission and choose to import them.

Information Ado stores

Ado stores information that you enter or create in the app, including projects, tasks, subtasks, descriptions, templates, completion state, ordering, and app preferences. This information is stored in Ado's private application storage on your device.

Calendar access

Ado may request read-only access to your device calendar. This permission is optional and is used when you choose to import calendar events into a daily list.

When you use that feature, Ado reads calendar event titles and timing information for the selected date and creates local list items from that information. Ado does not modify your calendar.

You can revoke calendar permission at any time in Android system settings. Revoking permission prevents future calendar reads, but it does not automatically remove items that you already imported into Ado. Those imported items can be deleted in the app like other list items.

Data collection and transmission

The current Android version of Ado does not use a developer-operated account system, advertising network, analytics service, or synchronization server. The app does not request Android's Internet permission and does not automatically transmit your project, task, or subtask data to the Ado developer.

Actions that send data outside Ado

Ado includes features that act only when you choose to use them:

  • Share: Ado can send task/list text to Android's system share sheet. The app or service you select to receive that text handles it under its own privacy practices.
  • Open links: Tapping an HTTP or HTTPS link can open a browser or another application. That external application or website handles the resulting activity under its own privacy practices.
  • Print: Printing uses Android's printing system and any print service you select.
  • Export and import: Ado can export a JSON backup to a location you select through Android's system file interface and can import a backup you select. Exported files are outside Ado's private storage and are controlled by you and the storage provider you choose.

Device and system backups

Ado currently permits standard Android application backup. Depending on your device, Android version, account settings, and backup configuration, Android or your device provider may include Ado application data in a device or cloud backup. Ado does not receive or control those system backups. Their handling is governed by the backup service you use.

Data sharing

Ado does not automatically sell, rent, or share your task data with advertisers, analytics providers, or a developer-operated server. Information leaves Ado only through user-directed features such as sharing, printing, opening a link, exporting a backup, or through operating-system backup behavior described above.

Security

Ado stores its working data in private application storage provided by Android. Access to that storage is controlled by the operating system. Ado's manually exported JSON backup files are not separately encrypted by Ado; the security of an exported file depends on the device, location, account, or storage provider where you choose to save it.

Retention and deletion

Ado keeps local app data until you delete the relevant items, clear Ado's application storage, or uninstall the app. Exported backup files remain wherever you saved them until you delete them there. Copies retained by Android or another system backup provider are subject to that provider's backup and retention rules.

Children

Ado is a general-purpose productivity application and is not designed specifically for children. The app does not knowingly operate an account, advertising, or analytics system that collects personal information from children.

Changes to this policy

If Ado's features or data practices change, this policy will be updated to describe those changes. The effective date at the top of this page will be updated when the policy materially changes.

Privacy questions

A public privacy contact has not yet been published. Contact information will be added before Ado is submitted for public distribution through an app store.
